### [IRONSIGHT](https://github.com/Noblerworks/IRONSIGHT) — Real-Time OSINT Command Center

50+ live data sources. One screen. Zero API keys. Completely free.

A real-time intelligence dashboard for monitoring the Middle East conflict, pulling live missile alerts, military aircraft positions, Telegram OSINT feeds, prediction markets, defense stocks, satellite thermal detection, and more into a single command center.

**Live data includes:**
- Missile alerts from Israel's Home Front Command (Pikud HaOref)
- Military aircraft tracking via ADS-B
- 27 Telegram intelligence channels with Hebrew/Arabic/Farsi auto-translation
- Polymarket prediction odds on conflict outcomes
- Defense contractor stocks, crypto, oil, and energy markets
- NASA FIRMS satellite fire/explosion detection
- Naval vessel tracking across the Persian Gulf and Red Sea

**Stack:** Next.js 16 | TypeScript | Tailwind CSS | Leaflet
